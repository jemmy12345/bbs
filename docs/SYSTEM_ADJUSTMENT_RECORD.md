# 系统优化与调整记录

记录项目整理和功能优化过程中的主要调整。

## 1. 项目结构整理

- 将项目整理为前后端分离结构，核心源码集中在 `smart-bbs` 目录。
- 后端统一放入 `backend`，前端统一放入 `frontend`。
- 数据库脚本放入 `sql`，运行脚本放入 `scripts`，说明文档放入 `docs`。
- 本机运行包放入 `deploy`，运行期数据和测试报告放入 `runtime`。

## 2. 数据库与运行环境

- 根据最新版数据库脚本补齐缺失字段和业务表。
- 修复 `sys_user` 中论坛积分字段缺失导致登录失败的问题。
- 统一演示账号密码为 `123456`，方便演示和验收。
- 将后端运行基线调整为 Java 17，提升外部 HTTPS 接口调用稳定性。
- 配置 Redis 本机运行路径，并保证后端能够正常连接 Redis。

## 3. 内容风控优化

- 发帖、评论、回复统一走后端风控兜底。
- 管理员、评审员、普通用户在论坛发帖、评论、回复时采用一致的风控规则。
- 优化前端风控提示时机，减少前后端提示不一致的问题。
- 评论和回复补充后端审核兜底，避免只依赖前端校验。
- 企业自定义敏感词库接入风控流程，保证自定义词能够参与审核判断。
- 审核不通过原因补充保存和展示能力，方便后台追踪。

## 4. 评论与互动修复

- 修复评论成功后偶发旧接口 404 提示的问题。
- 修复本人评论删除时误提示“只能删除本人的评论”的问题。
- 清理测试过程中产生的违规内容，保持演示数据整洁。
- 提案公示墙点赞改为可取消，再次点击可撤销点赞。
- 分享功能保持幂等，重复分享不重复累计。

## 5. AI 功能优化

- 优化 AI 助写连接异常时的错误提示。
- 保持 AI 助写和 AI 审核共用同一调用底层，减少功能间表现不一致。
- 针对 TLS 握手异常，明确推荐使用 Java 17 运行后端。

## 6. 提案模块优化

- 提案重复标题判断排除草稿，避免草稿影响正式提交。
- 修复提案附件上传按钮点击无反应的问题。
- 投稿页和进度更新区统一附件上传体验，上传后显示文件反馈。
- 修复提案列表中重复“已公示”标签的问题。
- 优化提案评审表单布局，评分控件和评审意见输入更清晰。
- 修复进度时间线排序异常，按实际时间顺序展示。
- 限制草稿编辑权限，避免评审角色编辑他人草稿。

## 7. 提案评审配置优化

- 初审、复审、终审分别固定对应角色：
  - 初审：`idea_l1_reviewer`
  - 复审：`idea_l2_reviewer`
  - 终审：`idea_l3_reviewer`
- 配置页不再手动选择处理角色，只选择具体处理人。
- 指定处理人列表仅展示当前环节对应角色下的账号。
- 如果普通账号需要参与某个评审环节，可在账号管理或角色管理中分配对应评审角色。
- 后端评审权限以指定处理人为准，角色仅用于候选范围，避免范围过宽导致流程混乱。
- 修复配置页多选新增或删除后不及时刷新的问题。

## 8. 后台账号管理修复

- 修复字符串用户 ID 账号进入修改页时报类型转换异常的问题。
- 补充字符串用户 ID 和数字字符串用户 ID 的接口验证。
- 保证 `l1reviewer`、`l2reviewer`、`l3reviewer` 等演示账号可以正常查看和维护。

## 9. 测试与验证

- 新增全量系统测试脚本：`scripts/full-system-test.ps1`。
- 覆盖登录、后台管理、帖子、评论、风控、提案提交、初审、复审、终审等流程。
- 补充账号管理和提案评审配置相关接口测试。
- 测试脚本支持重复运行，避免历史自动测试数据影响每日提案限制。
