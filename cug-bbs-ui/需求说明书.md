# Smart BBS 企业论坛系统需求说明书

## 1. 项目概述

### 1.1 项目背景
Smart BBS是一个基于RuoYi框架开发的企业论坛系统，旨在为企业内部提供信息交流、知识分享、问题讨论的平台。系统采用前后端分离架构，前端基于Vue.js + Element UI开发，支持PC端和移动端访问。

### 1.2 项目目标
- 提供便捷的论坛交流平台
- 支持匿名和实名发帖
- 实现内容审核和敏感词过滤
- 提供完善的用户管理和权限控制
- 支持多端访问（PC端、移动端）

### 1.3 技术架构
- **前端框架**: Vue.js 2.6.12
- **UI组件库**: Element UI 2.15.14
- **状态管理**: Vuex 3.6.0
- **路由管理**: Vue Router 3.4.9
- **HTTP客户端**: Axios 0.28.1
- **富文本编辑器**: Quill 2.0.2
- **国际化**: Vue-i18n 8.27.2

## 2. 功能需求

### 2.1 用户认证与权限管理

#### 2.1.1 用户登录
- **功能描述**: 支持多种登录方式
- **功能点**:
  - 普通账号密码登录
  - SSO单点登录
  - 自动登录功能
  - 登录验证码（可选）
- **业务规则**:
  - 登录成功后获取用户Token
  - 根据用户角色动态加载菜单和路由
  - 支持登录状态保持

#### 2.1.2 用户注册
- **功能描述**: 新用户注册功能
- **功能点**:
  - 用户信息填写
  - 注册信息验证
  - 注册成功后自动登录

#### 2.1.3 权限控制
- **功能描述**: 基于角色的权限访问控制（RBAC）
- **功能点**:
  - 角色管理（新增、编辑、删除、分配权限）
  - 用户角色分配
  - 菜单权限控制
  - 按钮级权限控制
  - 路由权限拦截
- **业务规则**:
  - 未登录用户只能访问白名单页面（登录、注册、论坛首页）
  - 已登录用户根据角色权限访问相应功能模块
  - 权限不足时跳转401页面

#### 2.1.4 个人中心
- **功能描述**: 用户个人信息管理
- **功能点**:
  - 个人信息查看和编辑
  - 头像上传和修改
  - 密码修改
  - 个人资料统计

### 2.2 BBS论坛核心功能

#### 2.2.1 论坛首页
- **功能描述**: 论坛主页面，展示帖子列表
- **功能点**:
  - 帖子列表展示（标题、作者、发布时间、浏览量、点赞数）
  - 帖子排序（最新、热门）
  - 分类筛选
  - 帖子搜索
  - 分页显示
  - 置顶帖子标识
  - 匿名帖子标识
- **业务规则**:
  - 支持按分类查看帖子
  - 支持按时间或热度排序
  - 支持关键词搜索

#### 2.2.2 帖子发布
- **功能描述**: 用户发布新帖子
- **功能点**:
  - 帖子标题输入
  - 帖子内容编辑（富文本编辑器）
  - 分类选择
  - 发布方式选择（实名/匿名）
  - 图片上传
  - 敏感词检测
  - 草稿保存
- **业务规则**:
  - 标题和内容必填
  - 发布前进行敏感词检测
  - 匿名发布不显示用户昵称和头像
  - 支持审核机制（可选）

#### 2.2.3 帖子详情
- **功能描述**: 查看帖子详细内容和评论
- **功能点**:
  - 帖子内容展示
  - 帖子信息展示（作者、发布时间、浏览量、点赞数、收藏数）
  - 点赞/取消点赞
  - 收藏/取消收藏
  - 评论列表展示
  - 评论发布
  - 评论回复
  - 评论点赞
  - 图片预览
- **业务规则**:
  - 匿名帖子不显示作者信息
  - 支持评论的嵌套回复
  - 评论支持图片上传

#### 2.2.4 帖子管理
- **功能描述**: 用户管理自己发布的帖子
- **功能点**:
  - 我的帖子列表
  - 帖子编辑
  - 帖子删除
  - 草稿管理

#### 2.2.5 分类管理
- **功能描述**: 帖子分类管理
- **功能点**:
  - 分类列表查看
  - 热门分类展示
  - 分类筛选

## 3. 非功能需求

### 3.1 性能需求
- 页面加载时间：首屏加载时间 < 3秒
- 接口响应时间：普通查询接口 < 1秒，复杂查询 < 3秒
- 支持并发用户数：≥ 1000
- 支持分页加载，每页默认20条数据

### 3.2 安全需求
- 用户密码加密存储
- Token认证机制
- 敏感词过滤
- XSS攻击防护
- SQL注入防护
- CSRF防护
- 权限验证

### 3.3 兼容性需求
- 浏览器兼容：Chrome、Firefox、Safari、Edge（最新两个版本）
- 移动端兼容：iOS Safari、Android Chrome
- 响应式设计，支持PC端和移动端自适应

### 3.4 可用性需求
- 系统可用性：≥ 99%
- 错误处理：友好的错误提示
- 操作提示：关键操作需确认
- 国际化支持：中文、英文

### 3.5 可维护性需求
- 代码规范：遵循Vue.js和JavaScript编码规范
- 代码注释：关键功能需有注释说明
- 模块化设计：功能模块独立，便于维护和扩展
